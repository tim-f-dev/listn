# Retired curriculum: before the Blasorchester rework

Archived on 2026-11-10 before replacing all 100 lesson configurations and names.

- `levels.json`: all original configurations, including titles, intervals, instruments, timing, root ranges and descriptions. Each lesson used ten questions.
- `levels.en.json` and `levels.de.json`: the original localized titles and descriptions.

This archive is reference material, not loaded by the app. To compare an old lesson with its replacement, match the numeric ID in `src/game/levels.ts`. The number identifies a permanent progress slot, not an immutable lesson. Existing earned scores and stars stay credited to the same slot. Do not restore this archive over current player saves.

The rework replaces the string/electric-heavy timbre distribution, the repetitive opening and all bilingual lesson names. See `LEVEL_DESIGN.md` for the current frequency table, every instrument appearance, adjacent-task audit and remaining missing Blasorchester sounds.
