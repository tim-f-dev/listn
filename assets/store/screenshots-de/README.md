1. 01-startseite.png — home
2. 02-levelpakete.png — pack selection

Captured from the running Expo web preview at localhost:8082 with a 360 x 640 CSS-pixel mobile viewport and devicePixelRatio 1. Original browser JPEG captures are in source/. The exports are resampled 3x using Lanczos; they are not native-resolution Android-device captures. No UI content was synthesized, retouched, or replaced. The adjacent ZIP contains only the four upload PNGs; the adjacent contact sheet is a review preview.

The German language and normal access mode were used for capture. Original English language, all-levels mode and default viewport were restored afterward. Existing scores/stars were preserved; the exercise was left without submitting an answer or saving a result.
